## 一、设计目标

### 1.1 核心目标

> 上线后，运营和开发需要"看到"什么、"控制"什么？

| 目标 | 说明 | 本次覆盖 |
|------|------|---------|
| 能看到业务运行状态 | 实时数据、趋势、异常 | ✓ |
| 能看到系统运行状态 | 资源、性能、错误 | ✓ |
| 能配置业务参数 | 开关、阈值、文案 | ✓ |
| 能处理异常情况 | 熔断、降级、限流 | ✓ |

### 1.2 用户角色

| 角色 | 需求 | 权限 |
|------|------|------|
| 运营 | 查看业务数据、配置运营参数 | 业务数据查看 + 业务配置 |
| 开发 | 查看系统状态、调试、应急处理 | 全部权限 |
| 产品 | 查看业务数据 | 业务数据只读 |
| 管理员 | 全部权限 | 全部权限 |

## 二、数据查看设计

### 2.1 业务数据看板

> 运营和产品需要看什么业务数据？

| 数据看板 | 展示内容 | 数据来源 | 更新频率 | 访问入口 |
|---------|---------|---------|---------|---------|
| 实时概览 | 核心指标实时值 | 业务埋点 | 实时 | 管理后台 |
| 趋势分析 | 指标趋势图 | 数据仓库 | T+1 | 管理后台 |
| 明细查询 | 单条数据详情 | 业务数据库 | 实时 | 管理后台 |

### 2.2 业务数据指标

| 指标名称 | 指标说明 | 数据来源 | 计算方式 | 展示方式 |
|---------|---------|---------|---------|---------|
| | | DB/埋点/数仓 | | 数字/图表/列表 |

### 2.3 系统运行数据看板

> 开发需要看什么系统运行数据？

| 看板 | 展示内容 | 数据来源 | 访问入口 |
|------|---------|---------|---------|
| 应用监控 | QPS/响应时间/错误率 | Prometheus | Grafana |
| 资源监控 | CPU/内存/磁盘/网络 | Prometheus | Grafana |
| 中间件监控 | DB/Redis/MQ | 各中间件监控 | Grafana |
| 链路追踪 | 请求链路 | SkyWalking/Jaeger | APM 平台 |

### 2.4 数据查询功能

| 查询场景 | 查询入口 | 查询条件 | 导出支持 |
|---------|---------|---------|---------|
| 订单查询 | 管理后台 | 订单号/用户/时间 | ✓ |
| 用户查询 | 管理后台 | 用户ID/手机号 | ✓ |
| 日志查询 | 日志平台 | traceId/关键字 | ✓ |

## 三、管理控制设计

### 3.1 业务配置管理

> 哪些业务参数需要通过管理后台配置？

| 配置名称 | 配置说明 | 默认值 | 配置方式 | 生效方式 |
|---------|---------|--------|---------|---------|
| 功能开关 | 控制功能是否开放 | 开 | 管理后台 | 实时生效 |
| 业务阈值 | 业务规则阈值 | | 管理后台 | 实时生效 |
| 文案配置 | 前端展示文案 | | 管理后台 | 实时生效 |
| 排序权重 | 列表排序规则 | | 管理后台 | 实时生效 |

### 3.2 系统配置管理

| 配置类型 | 配置项 | 配置方式 | 变更审批 | 生效方式 |
|---------|--------|---------|---------|---------|
| 应用配置 | 业务参数 | Nacos/Apollo | 不需要 | 实时/重启 |
| 中间件配置 | 连接池/超时 | 配置中心 | 需要 | 重启 |
| 环境变量 | 密钥/地址 | K8s ConfigMap | 需要 | 重启 |

### 3.3 应急控制

| 应急场景 | 控制操作 | 操作入口 | 权限要求 | 操作人 |
|---------|---------|---------|---------|--------|
| 服务熔断 | 开启/关闭熔断 | 管理后台 | 管理员 | |
| 功能降级 | 开启/关闭降级 | 管理后台 | 开发 | |
| 流量限制 | 调整限流阈值 | 管理后台 | 开发 | |
| 黑白名单 | 添加/删除名单 | 管理后台 | 运营 | |

### 3.4 数据操作

| 操作类型 | 操作内容 | 操作入口 | 权限要求 | 审批流程 |
|---------|---------|---------|---------|---------|
| 数据查询 | 查看明细 | 管理后台 | 查看 | 无 |
| 数据修改 | 修正错误数据 | 管理后台 | 编辑 | 需要 |
| 数据删除 | 删除无效数据 | 管理后台 | 删除 | 需要 |
| 数据导出 | 批量导出 | 管理后台 | 导出 | 需要 |
