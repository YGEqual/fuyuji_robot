# 技术方案目录结构说明

## 完整结构（中大型迭代）

```
yyyyMMdd_迭代主题/
├── 原始需求_DOC.md
├── 需求拆解_DOC.md
├── 技术方案/
│   ├── README.md                    ← 索引 + 状态 + 关键决策
│   ├── 01_整体架构设计.md            ← 服务拓扑、技术选型、部署架构
│   ├── 02_模块设计/
│   │   ├── 模块A_设计.md            ← 每个模块一份
│   │   ├── 模块B_设计.md
│   │   └── ...
│   ├── 03_数据流设计.md              ← 数据流转、缓存、MQ、存储
│   ├── 04_性能设计.md                ← 性能目标、瓶颈、优化方案
│   ├── 05_安全设计.md                ← 认证鉴权、防刷
│   ├── 06_可观测性设计.md            ← 日志、监控、告警、trace
│   ├── 07_运行管理控制设计.md        ← 管理后台、数据看板、动态配置
│   ├── 接口清单.md                   ← 所有接口汇总表
│   └── 表设计.md                     ← 数据库变更汇总
├── 工时评估_DOC.md
└── 编码实施计划_DOC.md
```

## 简化结构（小型迭代）

**适用条件（满足任一即可简化）：**
- 单服务变更，不涉及跨服务调用
- 改动范围 ≤ 3 个接口
- 无性能/安全/数据流方面的特殊要求

```
yyyyMMdd_迭代主题/
├── 原始需求_DOC.md
├── 需求拆解_DOC.md
├── 技术方案/
│   ├── README.md                    ← 索引（标注"简化版"）
│   ├── 01_整体设计.md                ← 合并：架构 + 模块 + 数据流
│   ├── 06_可观测性设计.md            ← 必须有（排障基础）
│   └── 接口清单.md                   ← 必须有
├── 工时评估_DOC.md
└── 编码实施计划_DOC.md
```

**简化版说明：**
- `01_整体设计.md` 合并了：架构、模块、数据流、性能、安全
- 如果涉及敏感数据或对外接口，仍需 `05_安全设计.md`
- 如果有性能要求，仍需 `04_性能设计.md`
- `06_可观测性设计.md` 和 `接口清单.md` 必须有，是排障和联调的基础

## 文档职责

| 文档 | 核心内容 | 给谁看 | 小迭代是否需要 |
|------|---------|--------|---------------|
| README.md | 状态、索引、关键决策、待确认项 | 全员 | 必须有 |
| 01_整体架构设计 | 服务拓扑、技术选型、部署架构 | 全员（评审入口） | 合并到整体设计 |
| 02_模块设计/ | 每个模块的职责、接口、实现细节 | 开发（具体实现者） | 合并到整体设计 |
| 03_数据流设计 | 数据流转、缓存策略、MQ、存储 | 开发 + DBA | 合并到整体设计 |
| 04_性能设计 | 性能目标、瓶颈、优化、压测 | 开发 + SRE | 按需 |
| 05_安全设计 | 认证鉴权、防刷、审计 | 开发 + 安全团队 | 按需 |
| 06_可观测性设计 | 日志规范、监控、告警、traceId | 开发 + SRE | **必须有** |
| 07_运行管理控制设计 | 管理后台、数据看板、动态配置 | 开发 + 运营 + SRE | 按需 |
| 接口清单.md | 所有接口汇总 | 开发 + 前端 + 测试 | **必须有** |
| 表设计.md | 数据库变更汇总 | 开发 + DBA | 按需 |

## 生成顺序

```
1. README.md          ← 先建索引，标明需要哪些文档
2. 01_整体架构设计.md  ← 先画大图
3. 02_模块设计/        ← 再拆细节（按模块逐个）
4. 03_数据流设计.md    ← 数据怎么流转
5. 04_性能设计.md      ← 性能目标（如有要求）
6. 05_安全设计.md      ← 安全相关（如有敏感数据/对外接口）
7. 06_可观测性设计.md  ← 日志监控（必须有）
8. 07_运行管理控制设计.md ← 管理后台（如有）
9. 接口清单.md         ← 从模块设计中汇总
10. 表设计.md          ← 从模块设计中汇总
```
