## 维度选择指引

不是每次都检查全部 7 个维度。根据迭代特点决定哪些适用：

| 迭代类型 | 必须维度 | 可选维度 |
|---------|---------|---------|
| 改一个字段 / 修 bug | 功能正确性 + 可维护性 | — |
| 新增接口 | 全部 7 个 | — |
| 性能优化 | 性能 + 功能正确性 + 可维护性 | 可观测性 |
| 重构 | 可维护性 + 可测试性 | 文档完整性 |
