## 四、详细设计

### 4.1 核心流程

```mermaid
sequenceDiagram
    participant 调用方
    participant Controller
    participant Service
    participant Repository
    participant Cache
    participant DB
    participant MQ
    调用方->>Controller: 请求
    Controller->>Service: 处理
    Service->>Cache: 查缓存
    alt 缓存命中
        Cache-->>Service: 返回数据
    else 缓存未命中
        Service->>Repository: 查DB
        Repository->>DB: 查询
        DB-->>Repository: 数据
        Repository-->>Service: 返回
        Service->>Cache: 写缓存
    end
    Service->>MQ: 发消息（异步）
    Service-->>Controller: 响应
    Controller-->>调用方: 返回
```
