## 四、索引设计说明

### 4.1 索引设计原则

1. **主键**：所有表必须有主键，推荐 BIGINT 自增或雪花 ID
2. **唯一索引**：业务唯一约束，命名 `uk_字段名`
3. **普通索引**：高频查询条件，命名 `idx_字段名`
4. **联合索引**：遵循最左前缀原则，命名 `idx_字段1_字段2`
