# 文档中心搭建方案

## 方案 A（推荐，语言无关）：静态文档中心 + 轻量服务托管

思路：文档中心本质是"静态站点"，任何语言都能托管；只要能把站点挂到 `/api-doc`（或网关前缀下）即可。

建议目录结构（示例）：

- `api-doc/`
  - `index.html`（导航页，可直接静态打开）
  - `api-doc-ui/`（查看器静态资源：`index.html`、`viewer.js`、`index.css` 等）
  - `docs/`（所有 Markdown 文档）
  - `docs/index.json`（文档树索引：分组/标题/路径/关键词）

接入规则：

1. **新建/更新 `docs/index.json`**：每条记录至少包含 `title`、`docPath`、`group`、`keywords`。
2. **导航页 `api-doc/index.html` 读取 `docs/index.json`**：渲染"分组树 + 搜索框 + 文档链接"。
3. **查看器 `api-doc-ui`**：从 `doc` 参数拿到 `docPath`，拉取对应 `*.md` 并渲染。

托管方式（按语言选一种）：

- Java/Spring：把 `api-doc/` 放到 `src/main/resources/static/`。
- Python/FastAPI：`StaticFiles` 挂载。
- Node/Express：`express.static` 挂载。
- Go/Gin：静态文件服务挂载。

## 方案 B（Spring Boot 强推荐）：/api-doc 后端导航 + /api-doc-ui 前端渲染

后端接口约定：

- `GET /api-doc`：导航页（HTML，按分组列出所有文档）。
- `GET /api-doc/{group}/{subGroup}/{simpleName}?format=md|html`

前端资源约定：

- `/api-doc-ui/index.html?doc={group}/{subGroup}/{simpleName}`
- 由 `viewer.js` 请求 `/api-doc/{doc}?format=md` 并渲染。

快速落地（从母版拷贝）：

- 静态资源：`<dataset>/arsenal-service-ai-dataset-api/src/main/resources/static/api-doc-ui`
- 后端参考：`<dataset>/arsenal-service-ai-dataset-api/src/main/java/com/ly/arsenal/ai/dataset/api/restful/doc/ApiDocController.java`

> 注意：如果 `_DOC.md` 放在 `src/main/java` 目录旁边，要确保构建会把 Markdown 打进包或运行时可读。如果不想跟构建对抗，直接放到 `src/main/resources` 体系里更稳。
